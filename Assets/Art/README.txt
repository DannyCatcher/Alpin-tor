This folder contains placeholder art locations and instructions.

Place your pixel-art PNG files here with the following suggested structure:
- Assets/Art/Backgrounds/sky.png
- Assets/Art/Backgrounds/mountains_far.png
- Assets/Art/Backgrounds/mountains_mid.png
- Assets/Art/Foreground/ground.png
- Assets/Art/Characters/alpinator_walk_0.png ... _1,_2
- Assets/Art/Items/flask.png

Set Unity import settings for pixel art:
- Texture Type: Sprite (2D and UI)
- Filter Mode: Point (no filter)
- Compression: None
- Pixels Per Unit: 32
